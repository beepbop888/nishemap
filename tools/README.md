# Локальная генерация аватаров

Работает на M1 без подписок и кредитов: Stable Diffusion 1.5 через diffusers на MPS.
Модель уже скачана в `~/.cache/huggingface` (~5 ГБ).

    python3.12 -m venv sdenv
    ./sdenv/bin/pip install torch torchvision diffusers transformers accelerate safetensors pillow
    ./sdenv/bin/python tools/ten.py          # 10 стилей × 5 персонажей

Замеры на M1/8 ГБ: загрузка модели ~11 мин, картинка 512×512 ~80 сек.
Скрипты возобновляемые — готовые файлы пропускаются.

## Важно про водяные знаки
Базовая SD1.5 обучена на стоках и дорисовывает логотипы iStock/Getty поверх картинки.
Слова `watermark` в негативе НЕ хватает — нужны имена стоков явным списком (см. `NEG` в ten.py).
Для коммерческого приложения это обязательная проверка каждой партии.

## Про промпты
Название стиля, которого не должно быть, нельзя писать в позитивном промпте даже с отрицанием:
«corporate memphis avoided» модель читает как «corporate memphis» и рисует именно его.
Всё исключаемое — только в негативе.
