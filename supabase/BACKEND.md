# Бэкенд НищеMap — Supabase (вердикт совета #2: мгновенные пины, без очереди)

## Что такое Supabase
Хостинг открытой БД Postgres с готовым REST API, файловым хранилищем и бесплатным тарифом.
Для нас: одна таблица `submissions` + bucket для фото меню. Сервер администрировать не надо.

## Настройка (≈10 минут, делает основатель — нужен аккаунт)
1. supabase.com → New project (Free tier), регион EU.
2. SQL Editor → вставить содержимое `01_core.sql` → Run.
3. Storage → New bucket → `menus`, галочка Public.
4. Settings → API → скопировать Project URL и anon public key
   → вставить в `config.js`: SUPABASE_URL и SUPABASE_ANON_KEY.
Форма начнёт слать в базу автоматически (см. js/app.js, ветка POST).

## Принципы (из вердикта)
- Сабмит → живой пин сразу (status='live'), БЕЗ очереди модерации: петля «сдал → увидел» = двигатель роста.
- Дешёвые предохранители вместо ворот: чек цены 1–500 в БД, рейт-лимит по ip_hash (edge function позже),
  кнопка «Пожаловаться» инкрементит flagged — просматривать раз в день, руками ставить hidden.
- Фото: ТОЛЬКО меню, ценник или сама еда — правило повторяется в UI и проверяется модерацией (селфи/люди → hidden). Два потока: поле в форме сабмита и кнопка «📷 фото» у каждой позиции (таблица item_photos) → bucket `menus`,
  photo_url в строке. Фото = доказательство цены и контент для карточки.
- Координаты: адрес геокодится клиентом при отображении (ymaps.geocode) либо модератором при первом просмотре.
