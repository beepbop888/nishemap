# Включить пятничную рассылку — 5 шагов

Бот раз в неделю (пятница, 15:00 МСК) присылает подписчикам топ-5 мест недели.
Каждое место — ссылка: тапнул и сразу открылась эта точка на карте.

---

## Шаг 1. Создать таблицы (2 минуты)

1. Открой **supabase.com** → войди → проект **nishemap**.
2. Слева нажми **SQL Editor**.
3. Нажми зелёную **+ New query**.
4. На компьютере открой файл `Desktop → Claude Projects → Jaison → supabase → 04_digest.sql`.
5. Выдели всё (**Cmd+A**), скопируй (**Cmd+C**).
6. Вставь в окно Supabase (**Cmd+V**) и нажми **Run** (или Cmd+Enter).
7. Должно появиться **Success. No rows returned**. Готово.

---

## Шаг 2. Взять токен бота (1 минута)

1. Открой Telegram → найди **@BotFather**.
2. Отправь ему: `/mybots`
3. Выбери **@nishemap_bot** → **API Token**.
4. Скопируй строку вида `8123456789:AAH...` — это **BOT_TOKEN**.

---

## Шаг 3. Взять секретный ключ базы (1 минута)

1. Supabase → проект **nishemap** → слева внизу **Settings** (шестерёнка).
2. Раздел **API**.
3. Найди блок **Project API keys** → строка **service_role** → нажми **Reveal** → скопируй.
   Это **SUPABASE_SERVICE_KEY**.

⚠️ Этот ключ = полный доступ к базе. Он идёт ТОЛЬКО в секреты GitHub (шаг 4).
Никогда не вставляй его в config.js и никуда на сайт.

---

## Шаг 4. Положить три секрета в GitHub (3 минуты)

1. Открой https://github.com/beepbop888/nishemap
2. Вкладка **Settings** (справа сверху, в меню репозитория).
3. Слева: **Secrets and variables** → **Actions**.
4. Кнопка **New repository secret**. Добавь три штуки, по одной:

   | Name (скопируй точно) | Secret (значение) |
   |---|---|
   | `BOT_TOKEN` | токен из шага 2 |
   | `SUPABASE_URL` | `https://svfnjfpawljkdcehzkgv.supabase.co` |
   | `SUPABASE_SERVICE_KEY` | ключ service_role из шага 3 |

   Каждый раз: вписал Name → вставил Secret → **Add secret**.

---

## Шаг 5. Проверить прямо сейчас (1 минута)

1. В Telegram напиши своему боту **@nishemap_bot** сообщение `/start`
   (это подписывает тебя на рассылку).
2. GitHub → репозиторий → вкладка **Actions**.
3. Слева выбери **НищеMap Telegram digest**.
4. Справа кнопка **Run workflow** → поставь галочку **Отправить дайджест сейчас** → **Run workflow**.
5. Подожди минуту, обнови страницу — задача должна стать зелёной ✅.
6. Проверь Telegram: должно прийти сообщение от бота.

Если топ-5 пуст (никто ещё не смотрел точки на карте) — бот ничего не пришлёт,
это нормально. Открой несколько карточек на карте и запусти ещё раз.

---

## Дальше само

- Каждые 6 часов бот подбирает новых подписчиков (кто нажал `/start`).
- Каждую пятницу в 15:00 МСК уходит рассылка.
- Ничего запускать руками больше не нужно.
