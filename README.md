# НищеMap (project Jaison)

Карта еды до 500 ₽ в Москве. Монеты (золото ≤100 / серебро 101–200 / бронза 201–300) + фиолет (купюра, 301–500). Вдохновлено корейским Geojimap («карта нищих»).

- Статика: `index.html` + `css/` + `js/` + `data/seed.js` (генерируется из `data/seed.json`)
- Карта: Яндекс Карты JS API 2.1 (ключ в `config.js` — при публикации репо ограничить ключ по HTTP-referer в кабинете Яндекса)
- Данные: реальные заведения из публичных подборок, цены не проверены на месте — бейджи честно это показывают; проверка = краудсорсинг
- Планы: Supabase-бэкенд для мгновенных пользовательских пинов → Telegram/VK Mini Apps → RuStore
- Полевой чеклист для сбора данных: `SEEDING.md` · Решения и вердикты советов: `council-report-*.html`

Запуск: открыть `index.html` (или `python3 -m http.server`).
