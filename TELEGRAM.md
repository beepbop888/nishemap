# НищеMap как Telegram Mini App

Код уже готов: приложение само определяет, что открыто внутри Telegram
(`window.Telegram.WebApp`), разворачивается на весь экран, красит шапку Telegram
в чёрный цвет вывески, использует системную кнопку «Назад» для закрытия карточки
и даёт вибро-отклик после отправки точки. Ничего дописывать не нужно.

## Что осталось (5 минут, нужен твой Telegram)

1. Сначала сайт должен быть по HTTPS-адресу (GitHub Pages):
   `https://beepbop888.github.io/nishemap/` — Telegram не принимает localhost.
2. В Telegram: **@BotFather** → `/newbot` → имя `НищеMap` → username, например `nishemap_bot`.
3. Там же: `/newapp` → выбрать бота → название, описание, картинку 640×360 →
   **Web App URL**: `https://beepbop888.github.io/nishemap/`
4. BotFather выдаст ссылку вида `t.me/nishemap_bot/app` — это и есть мини-апп.
   Её и кидают в студенческие чаты.
5. По желанию: `/setmenubutton` → «Открыть карту» — кнопка появится в чате с ботом.

## Что уже делает код внутри Telegram
- `expand()` — сразу на весь экран, без «шторки».
- Шапка Telegram = `#232323`, фон = цвет бумаги: приложение выглядит родным.
- Системная «Назад» закрывает карточку заведения и форму.
- Haptic feedback при успешной отправке цены.
- Геолокация и «поделиться» работают через обычные веб-API — Telegram их поддерживает.
